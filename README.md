# WordPress Developer Single-Page Portfolio

## Files
- `index.html` — complete single-page structure
- `style.css` — responsive styling and animations
- `script.js` — mobile menu, smooth scrolling, validation, dynamic year
- `favicon.svg` — W + code-bracket favicon
- `images/` — place your real portrait/project images here

## Run locally
Open `index.html` directly in a browser, or use VS Code + Live Server.

## Replace placeholders
1. The supplied professional portrait is already added as `images/portrait.jpg`. Replace it with another photo anytime.
2. Add real project thumbnails and project URLs.
3. Replace Email, LinkedIn, and WhatsApp placeholders.
4. Connect the contact form to a real backend/form service.

## Contact form
The frontend validates required fields and email format, but intentionally does not claim successful submission. Connect the submit handler in `script.js` to your backend or form service and only show success after the backend confirms delivery.

## WordPress use
This is a standalone HTML/CSS/JS portfolio. It can be converted into an Elementor/WordPress template later if needed.
